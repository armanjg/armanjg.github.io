# Selected Coursework

Clean standalone Overleaf project for Arman Jahangiri's Selected Coursework document.

## Build
- Main document: `main.tex`
- Compiler: pdfLaTeX
- No custom class, bibliography database, figures, or external project files are required.

## Organization
The document contains 53 course entries, organized by subject area rather than by institution or degree level. Each course has a brief italic context line, followed by its substantive topics, texts/references, and (where useful) a source or note.
